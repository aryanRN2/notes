let $g_1 * a = g_2 * a$
$\Rightarrow g_2^{-1} * (g_1 * a) = g_2^{-1} * g_2 * a$

$\Rightarrow (g_2^{-1} g_1) * a = e * a = a$
$\Rightarrow g_2^{-1} g_1 \in G_a$
$\Rightarrow g_1 G_a = g_2 G_a$
$\Rightarrow \phi(g_1 * a) = \phi(g_2 * a)$

$\therefore \phi$ is a map.
Let $\phi(g_1 * a) = \phi(g_2 * a)$
$\Rightarrow g_1 G_a = g_2 G_a$
$\Rightarrow g_1 g_2^{-1} \in G_a$
$\Rightarrow g_2^{-1} g_1 * a = a$
$\Rightarrow g_2 * g_2^{-1} g_1 * a = g_2 * a$
$\Rightarrow g_1 * a = g_2 * a$
$\therefore \phi$ is one-one.
Now,
if $t \in G/G_a$
$\Rightarrow t = g G_a, g \in G$
$\Rightarrow g * a \in G^a$ s.t. $\phi(g * a) = g G_a = t$
$\Rightarrow \phi$ is onto.

Note: If $G$ is a finite group then
$|G^a| = |G/G_a| = \frac{|G|}{|G_a|}$

$\Rightarrow |G| = |G^a| |G_a|$
