# 🐍 Numerical Computing in Python: Complete Practical Handbook

Theoretical formulations, step-by-step procedural Python 3 implementations, and iteration convergence tables for 20 fundamental numerical methods.

## 📚 Master Handbooks & PDFs
- **`Numerical_Computing_Python_Handbook.pdf`** / **`handbook.tex`**: Complete laboratory manual with code, theory, and formatted iteration tables.
- **`codes_by_sciqb.pdf`** / **`codes_by_sciqb.tex`**: Production laboratory reference with source code and program execution outputs.

## 💻 20 Core Numerical Methods (`detailed/`)
1. **`01_bisection_detailed.py`**: Bisection Method for nonlinear roots.
2. **`02_regula_falsi_detailed.py`**: False Position (Regula Falsi) Method.
3. **`03_newton_raphson_detailed.py`**: Newton-Raphson quadratic convergence method.
4. **`04_secant_detailed.py`**: Secant root-finding method.
5. **`05_fixed_point_detailed.py`**: Fixed-Point Iteration $x_{k+1} = g(x_k)$.
6. **`06_gauss_elimination_detailed.py`**: Gaussian Elimination with partial pivoting.
7. **`07_gauss_jordan_detailed.py`**: Gauss-Jordan matrix inversion and solver.
8. **`08_gauss_jacobi_detailed.py`**: Gauss-Jacobi iterative linear system solver.
9. **`09_gauss_seidel_detailed.py`**: Gauss-Seidel accelerated iterative method.
10. **`10_lagrange_detailed.py`**: Lagrange polynomial interpolation.
11. **`11_newton_divided_diff_detailed.py`**: Newton's Divided Difference interpolation.
12. **`12_newton_forward_detailed.py`**: Newton's Forward Difference formula.
13. **`13_trapezoidal_detailed.py`**: Composite Trapezoidal rule for numerical integration.
14. **`14_simpson_1_3_detailed.py`**: Simpson's 1/3 rule ($O(h^4)$ accuracy).
15. **`15_simpson_3_8_detailed.py`**: Simpson's 3/8 rule.
16. **`16_euler_detailed.py`**: Forward Euler method for initial value ODEs.
17. **`17_modified_euler_detailed.py`**: Heun's / Modified Euler predictor-corrector.
18. **`18_rk4_detailed.py`**: Classical 4th-order Runge-Kutta method (RK4).
19. **`19_power_method_detailed.py`**: Power Method for dominant eigenvalues and eigenvectors.
20. **`20_linear_fit_detailed.py`**: Least-squares linear curve fitting.
